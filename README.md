### Основной проект
 **[`final project`](./final%20project/)** — Исследование структуры образа жизни студентов и его взаимосвязи с академическими результатами
 
**Задача:** выявить, какие факторы образа жизни наиболее связаны с успеваемостью студентов

**Методы:** EDA, t-тест, χ², ANOVA, bootstrap, линейная регрессия, KMeans

**Результат:**
- R² = 0.55 — модель объясняет 55% дисперсии оценок, основной фактор — количество часов учёбы
- Кластеризация выделила 3 сегмента студентов

**Стек:**

`Pandas`, `NumPy`, `Matplotlib`, `Seaborn`, `Scipy`,` Sklearn`
